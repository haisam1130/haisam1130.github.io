History & Mystery Shorts Automation is a personal tool for producing English History & Mystery videos. It combines reference-based storytelling, narrated audio, story-aligned licensed images and optional footage, animated camera motion, optional source-supported maps and timelines, timed captions, and a YouTube upload adapter controlled by the channel owner.

What the app does

The production workflow runs in the operator's private GitHub repository. It prepares scripts, narration, vertical videos, and descriptions. Google authorization is used only to enable uploads to the YouTube account selected during consent.

The owner approved two daily Public-upload attempts at 09:00 and 18:00 Asia/Dubai. The automation checks the authorized channel before each upload. Public publishing depends on Google's API requirements: if a requested Public upload is returned as Private, or an upload result is uncertain, further generation and uploads are blocked for owner review. This website is informational: it does not provide a public sign-in, collect Google passwords, or grant access to the production workflow.

The app is operated by the owner of the GitHub account haisam1130. It is not a Google or YouTube product.

Data & permissions

Privacy policy

Last updated: 6 October 2026.

Scope and contact

This policy describes the personal History & Mystery Shorts Automation workflow and its informational website. The workflow is for the operator's own channel, not a public account-management service. For questions or deletion requests, contact haisam1130@gmail.com.

Google data accessed and used

The app requests the Google OAuth permissions youtube.upload and youtube.readonly. The read-only permission allows viewing YouTube account data; this workflow uses it only to retrieve the authorized channel's ID, title, and handle and verify the upload destination. When uploads are enabled, it sends the generated video file and its title, description, tags, and upload settings to YouTube. It receives upload results such as the video identifier. The workflow does not request Gmail, Drive, contacts, viewer profiles, YouTube analytics, or advertising-account access.

OAuth access tokens, refresh tokens, and OAuth client credentials authorize the upload adapter. The app does not ask for or store the operator's Google password. The operator chooses the destination Google account or YouTube channel during authorization.

Storage and security

Production credentials are stored as secrets in the private GitHub repository and restored to temporary credential files when needed. Local or Codespaces authorization can also create a token file that the operator must protect and delete when no longer needed. Credentials are not intended for public repositories, public websites, or preview artifacts.

Generated videos, scripts, reference URLs, visual credits, and speech timestamps may be retained in output folders and GitHub Actions artifacts. Preview artifacts currently have a three-day retention setting. Public Pixabay search results are cached for at least 24 hours; cached results contain media metadata, not OAuth credentials or the API key. Topic history and workflow logs may remain longer; the operator controls their deletion. OAuth credentials remain until the operator removes them or replaces them. Provider backups and operational logs follow each provider's own practices.

Service providers and sharing

GitHub hosts the private workflow and secrets. Google and YouTube process authorization and uploads. OpenAI receives topic-generation and script prompts, including instructions for source-supported story visuals; the script-generation code does not intentionally send Google OAuth tokens or private YouTube account data to OpenAI. Edge TTS receives narration text. Pixabay and Wikimedia receive visual search terms and serve licensed images; Pixabay may also supply licensed video footage. Wikipedia supplies public reference text. Country locator graphics use bundled public-domain Natural Earth data; rendering them does not send Google account data to Natural Earth. These providers process requests under their own terms and privacy practices.

The informational website uses no application analytics, advertising scripts, or sign-in form. Its hosting provider may process IP addresses and request logs. Fontshare serves the website's fonts and receives browser requests. Email messages sent to the contact address are handled by the email provider.

Limits on Google user data use

Google user data is used only for the authorized upload function and the support or security needed to operate it. It is not sold, used for personalized advertising, or supplied to an AI service to train a generalized model. Human access is limited to the operator and anyone the operator expressly authorizes for necessary support or security.

The app's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. This statement is not an assertion that Google has verified the app.

Revocation and deletion

The operator can stop all future jobs by disabling the GitHub Actions workflow. Google authorization can be revoked through the Google Account's third-party connections settings. Revocation prevents further authorized API use but does not delete videos already uploaded to YouTube or copies retained in GitHub.

To complete removal, the operator must delete the YouTube token and client secrets from GitHub, remove local or Codespaces credential files, and delete retained outputs, artifacts, or logs containing account-related upload results. Deletion is manual, not automatic. Requests sent to the contact email will be handled by the operator. Removal of published videos must be performed separately in YouTube Studio.

Children and policy changes

The app is an owner-operated production tool and does not offer registration to children. If the workflow, providers, requested Google scopes, retention practices, or public features change, this policy must be updated before those changes are used.
